# Vercel 极简热点网格设计

## 目标

将热点首页改造成克制、清晰、易扫描的 Vercel 风格网格。界面应依靠排版、留白、细边框和稳定对齐建立层级，不使用装饰性渐变、光效、厚重阴影或大量彩色胶囊。

本轮只调整首页热点浏览体验，不改动数据请求、来源逻辑、收藏行为、认证流程或路由协议。

## 范围

调整以下区域：

- 首页背景、内容宽度与基础视觉令牌
- 顶部品牌和账户操作区
- 热点来源导航
- 搜索与时间筛选工具栏
- 热点卡片网格
- 加载、错误、空数据和“加载更多”状态

不在本轮调整：

- Prisma、API、服务端和趋势源数据结构
- 收藏面板、登录弹窗和推送设置的功能逻辑
- 当前工作区中已有的通知功能改动

## 视觉语言

- 页面背景使用中性浅灰，内容表面使用白色。
- 文本以近黑、深灰和中灰构成三级层级。
- 分隔依赖 `1px` 中性边框。
- 圆角控制在 `8–12px`，不使用大面积胶囊形状。
- 阴影仅用于悬停反馈，范围小、透明度低。
- 主要交互使用黑白或中性色；绿色只表示上升或成功状态。
- 深色模式延续同一层级关系，不引入蓝色发光效果。

## 页面结构

### 顶栏

- 保留产品名称、收藏入口、主题切换和账户入口。
- 去掉装饰性品牌动画和渐变 Logo。
- 顶栏高度紧凑，使用白色背景和底部分隔线。
- 次要图标按钮默认无边框或使用极弱边框，悬停时显示浅灰背景。

### 来源导航

导航顺序固定为：

1. AI
2. Python
3. Github
4. Node
5. React
6. Vue
7. npm
8. 组件库
9. V2EX
10. 知乎
11. 掘金
12. 微博

交互规则：

- 桌面端为单行横向导航。
- 活动项使用深色文字和 `2px` 底部指示线。
- 非活动项使用中灰文字，悬停时加深。
- 宽度不足时允许横向滚动，并保留现有左右滚动能力。
- 不使用彩色来源徽标或大面积选中背景。

### 搜索与时间筛选

- 搜索框和时间筛选位于同一行。
- 搜索框占用剩余宽度，时间筛选保持内容宽度。
- 控件统一使用 `8px` 圆角、白色背景和细边框。
- 重置使用图标按钮，并提供 `aria-label` 和悬停提示。
- 移动端改为纵向排列，来源导航仍可横向滚动。

## 热点卡片

### 网格

- 移动端一列。
- 平板端两列。
- 常规桌面端三列。
- 超宽屏保持三列，避免卡片变窄或信息过密。
- 网格间距统一为 `12–16px`。

### 卡片层级

每张卡片按以下顺序展示：

1. 排名、来源和更新时间
2. 标题
3. 项目标识或完整名称
4. 描述
5. 核心指标
6. 收藏、复制和打开详情操作

规则：

- 卡片使用白色背景、细边框和 `10–12px` 圆角。
- 标题最多一行，描述最多三行。
- 卡片高度保持一致，指标和操作固定在底部。
- 排名使用低对比中性样式；前三名不使用金色发光或醒目奖牌。
- 指标不再使用多个彩色胶囊，改为轻量文字组或带小图标的中性信息。
- 收藏、复制和详情操作使用图标按钮；默认弱化，悬停卡片时提高可见度。
- 卡片悬停只允许轻微上移、边框加深和极弱阴影。

## 加载更多

- 使用居中的纯图标按钮，不显示“加载更多”文案。
- 默认图标使用向下箭头或向下展开图标。
- 加载时在同一尺寸按钮内切换为旋转加载图标，避免布局跳动。
- 按钮尺寸为 `36 × 36px`，圆角为 `8px`，使用白色背景和细边框。
- 悬停时仅加深边框和背景，不产生位移或大阴影。
- 按钮必须提供 `aria-label="加载更多"`。
- 桌面端悬停时可显示 Tooltip“加载更多”；移动端不依赖 Tooltip。
- 禁用状态降低透明度并阻止重复请求。
- 没有更多内容时不渲染按钮。

## 状态设计

- 骨架屏与最终卡片使用相同网格、尺寸和圆角。
- 错误状态使用中性卡片承载，错误文字和重试动作清晰，不使用大面积红色背景。
- 缓存提示使用紧凑的琥珀色提示条。
- 空状态只保留一句说明，不添加插画或装饰。
- 加载更多过程中现有卡片保持可见。

## 响应式与可访问性

- 所有图标按钮保留可读的 `aria-label`。
- 键盘焦点使用清晰但克制的焦点环。
- 触控按钮最小可点击范围不小于 `36px`。
- 支持 `prefers-reduced-motion`，关闭非必要位移动画。
- 文本和背景满足常规正文对比度要求。

## 验收标准

- 来源导航顺序与设计一致。
- 卡片在桌面端保持三列，并在移动端正确降为一列。
- 卡片内没有彩色指标胶囊和大圆角容器堆叠。
- “加载更多”只显示图标，加载前后尺寸不变。
- 现有搜索、筛选、收藏、复制、跳转和分页功能保持可用。
- 浅色和深色模式均保持清晰层级。
- `pnpm lint` 和 `pnpm build` 通过；若构建受环境或数据库影响，记录具体原因。
